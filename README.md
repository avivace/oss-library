# OSS Library

A collection of books, articles, talks, papers, blog posts, podcasts and opinions on (F)OSS, licenses and OSPOs (Open Source Program Offices), for open source practitioners and anyone building or consuming open source software.

Browse and search it at **[ossl.avivace.com](https://ossl.avivace.com)**.

## Books

- Working in Public: The Making and Maintenance of Open Source Software - Nadia Eghbal (2020)
- Program Management for Open Source Projects - Ben Cotton (2022)
- [OSPO Book](https://ospobook.todogroup.org/) - TODO Group (2025)
